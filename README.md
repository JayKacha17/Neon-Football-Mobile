# Neon Football Mobile (LAN & Offline Edition)

A premium 3D arcade multiplayer football game designed for mobile devices. Play with friends over local Wi-Fi or mobile hotspot with **0 internet required**.

## Features
- **0 Internet Required**: Runs completely offline using bundled Three.js and Matter.js engines.
- **Wi-Fi LAN & Hotspot Multiplayer**: Connect multiple phones over the same Wi-Fi router or phone hotspot.
- **Solo Offline Practice Mode**: Play anywhere against intelligent AI goalkeeper bots directly on your mobile device.
- **Touch Virtual Joystick & Dynamic Camera**: Responsive analog thumbstick, power kick (shoot), tackle/pass, and sprint boost.
- **Radar Minimap & Match HUD**: Real-time pitch radar, scoreboard, timer, and goal animations.
- **PWA & Native APK Ready**: Install directly to mobile home screen or package with Capacitor into an Android APK.

## How to Play
See [HOW_TO_PLAY_OFFLINE.md](HOW_TO_PLAY_OFFLINE.md) for step-by-step instructions.

### 1-Click Launch (Windows)
- Run `START_LAN_SERVER.bat` to host a local Wi-Fi match.
- Run `OPEN_MOBILE_GAME.bat` to launch the mobile game immediately in your browser.
